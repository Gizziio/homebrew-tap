# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in the packages distributed through
this tap (Allternit Desktop, Gizzi Code CLI), please report it privately to:

**security@allternit.com**

Please include:

- A description of the vulnerability and its impact
- Affected package, version(s), and platform(s)
- Steps to reproduce (proof-of-concept, if available)

Do **not** open a public GitHub issue for security vulnerabilities.

## Response

- We aim to acknowledge reports within 3 business days.
- We will coordinate a fix and disclosure timeline with you before any public
  announcement.
